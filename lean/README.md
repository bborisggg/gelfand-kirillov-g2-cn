# Formal statements in the supplement

The sources use Lean 4.28.0 and its standard library. To rebuild in a clean temporary directory and inspect the dependencies of every public theorem, run

    python verify.py

To retain compiled files and the raw output of Lean's axiom printer, run

    python verify.py --output rebuilt

The build order and fully qualified names appear in modules.json. Axioms.txt records the native build delivered here. All 59 public theorems were checked. Their reported dependencies are subsets of propext, Classical.choice and Quot.sound.

For the Jacobian calculation put X = diag(x,y,−x−y) and take the three rows of Y to be (u,1,c), (d,v,1), (g,h,−u−v). Use the traces of X², XY, Y², X³, X²Y, XY², Y³ and X²Y² in that order. At (x,y,u,v,c,d,g,h) = (0,1,0,0,0,0,1,0) the determinant of their Jacobian is −288. In characteristic zero the Jacobian criterion implies algebraic independence. Proposition 5.1 obtains generation from the invariant-theory presentation of Aslaksen, Drensky and Sadikova.

The formalization ends at these specified statements. The application of Harish–Chandra's central-character theorem to the abstract enveloping algebra, the identification of Premet's finite W-algebra with the full invariant differential algebra, and the valuation, Brauer, modular and parabolic deductions in the main theorem are proved in the manuscript.
